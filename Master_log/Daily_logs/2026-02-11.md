## Convert `sint` to  `sbit`
It is possible to convert a single `sint` to a `sbit` using the the following code.
```python
sb = sbit.get_type(1)
zero_as_sint = sint(0)
c = sbitvec(zero_as_sint, 1, 1)[0]
print_ln("c: %s and type: %s", c.reveal(), type(c))
```
