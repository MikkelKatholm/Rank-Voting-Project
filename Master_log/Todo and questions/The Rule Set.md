# Meta info
The report is typeset using LaTeX in overleaf.

# Headers
## Chapters, sections, subsection, subsubsections
1. All words in the header must start with a capital letter, except for *minor words* or *function words* like:
	- or, the, with, a, for, to, is
	- eg. This Captions is a Header
2. `&` Must be used and not the word `and`
3. Contain no `,` `;` `:` `.` or any other non letter words except for `-`
4. Starting letter must always be capitalized even if it is a *minor words* or *function words* 

## Paragraph & description environments
Same rules as in **Chapters, sections, subsection, subsubsections** except for rule 3
3. Must end with a colon `:`

## Consistency Rules
1. `ElGamal` Not any other variant
2. When referencing using cleveref it must be `\Cref{}` not `\cref{}` thus when referencing the section table or whatever must be capitilized.
3. `Secure Multiparty computation` Not something else
4. `Zero-knowledge` NOT `Zero knowledge` (Must use the dash)
5. `Mix-Net(s)` NOT `Mix net` or any other variant 
6. Use the term `Tallying` and not `Tabulatioin`
7. We use `Secret sharing` not `Secret-sharing`
